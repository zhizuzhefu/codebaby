# 屏幕文字识别（OCR）

> `codebaby guide ocr` · 桌面端：步骤编辑器地址栏旁的「识别文字」按钮读出屏幕上的文字并给出可直接选用的定位

界面结构里读不到文字的页面（微信小程序、自绘控件、Canvas、游戏、远程桌面里的窗口），`role` / `id` / `text` 都找不到东西。`ocr` 换一种办法：**对截图做文字识别，按屏幕上看到的字定位**——和人看屏幕一样。

- Web、Android、Mac 桌面三种用例通用，步骤、等待、断言、捕获的写法不变，只是把定位换成 `ocr`
- 识别在运行 codebaby 的这台机器上完成：不联网、不调用大模型、不消耗 token；同一张图每次识别结果一致
- 目前支持 macOS（系统自带的 Vision 框架，不用装任何软件；识别中文需要 macOS 13 及以上）
- **有界面结构时优先用结构定位**（`role` / `id` / `text`）：更快更稳。`ocr` 用在结构读不到的地方

## 一个完整的用例

```json case
{
  "name": "预约页没有可约号源",
  "android": {
    "app": "com.tencent.mm",
    "attach": true,
    "steps": [
      { "expect": { "ocr": "选择医生" } },
      { "expect": { "ocr": "已约满", "region": { "x": 0, "y": 0.14, "w": 1, "h": 0.06 }, "count": 5 } },
      { "expect": { "ocr": "已约满", "row": "张三" } },
      { "expect": { "ocr": "立即预约", "state": "hidden" } },
      { "tap": { "ocr": "其他院区号源查看", "nth": 0 } },
      { "expect": { "ocr": "*", "hasText": "院区" }, "capture": { "fee": { "ocr": "挂号费", "regex": "[¥￥]\\s*(\\d+)" } } }
    ]
  }
}
```

`attach: true`：接管设备上现在停着的页面，不启动也不关闭应用（微信小程序要先手动走到目标页，见 `guide android`）。

## 写法

`ocr` 和 `role` / `name` / `id` / `text` / `css` 等结构定位**二选一**，其余写法和普通定位一样。

| 字段 | 作用 |
|------|------|
| `ocr` | 屏幕上看到的文字。忽略空白、全角半角（`￥` / `：`）、大小写，**包含**即可；写 `"*"` = 区域内的全部文字 |
| `exact` | 整行文字相等（缺省包含） |
| `nth` | 匹配到多个时取第几个（从 0 起，按阅读顺序：自上而下、同一行自左而右）；不写且匹配到多个会报错，避免点错 |
| `region` | 只识别、只查找屏幕的这一块：`{"x","y","w","h"}` 取 0~1，是占整张截图的比例（左上角为原点），与分辨率无关。**更快也更准**，还能避开状态栏时钟之类每次都变的内容 |
| `row` | 只取和这行文字在同一横排的结果：`{"ocr": "已约满", "row": "张三"}` = 「张三」那一行的「已约满」。这行文字要在 `region` 之内 |
| `fuzzy` | 容错：允许识别结果与期望的文字相差几个字（最大 5，缺省 0）。有完全相同的就不再模糊匹配 |
| `minConfidence` | 忽略置信度低于它的识别结果（0~1，缺省 0.3） |
| `hasText` | 命中那行文字包含这段（在多个匹配里筛选，或断言文字内容） |
| `count` | 命中的个数：数字 = 恰好；或比较 `{"gt": 0}` / `{"gte": 1, "lt": 5}`（`gt` / `gte` / `lt` / `lte`） |
| `state` | 只能写 `visible`（缺省）/ `hidden`：判断文字出现或消失 |
| `regex` | 在 `capture` 里从识别到的文字取值（有分组取第 1 组） |

- **点击**点的是匹配到的那几个字的中心，不是整行；**填写** `fill` = 点它、清空、输入（适合标签或占位文字本身就是输入框的一部分的界面）
- **`"*"`** 把区域内的全部文字按阅读顺序合成一处（同一横排用空格连接，换行分行），用来整块捕获或断言
- 每一步等到**连续两次识别位置一致**才操作，避免点在动画中的位置上
- 同一张画面不会重复识别（等待时每 250ms 轮询一次，画面没变就直接用上次的结果）

## 先看识别到了什么

```
codebaby android snapshot --ocr          # 手机当前界面
codebaby web snapshot <地址> --ocr       # 网页
codebaby desktop snapshot <应用> --ocr   # Mac 应用窗口
```

列出屏幕上每一行文字和可直接粘贴的 `ocr` 定位（同样的文字出现多次时自动带上 `nth`），并把识别到的每一行用绿框标在截图上。桌面端点「识别文字」是同一个功能。

用例失败时，原因里会写出**屏幕上实际识别到的文字**，失败现场多一个 `ocr.json`（全部文字、位置、置信度），对照着改写法；通过的步骤会记下命中几处和置信度。

## 精度与稳定

- 识别结果有置信度：单个汉字、白字绿底这类容易偏低（0.3~0.5），整行文字通常是 1.0。用多字的词定位比单字稳
- 容易混淆的字（已 / 己、未 / 末）：先用 `snapshot --ocr` 看实际识别成什么，必要时加 `fuzzy: 1`，或改用旁边更独特的文字
- 画面里每次都变的内容（时间、电量、动图）用 `region` 避开
- 屏幕分辨率、缩放变了，`region` 的比例不变，仍然适用；字号差别很大时重新看一下识别结果

## 三端的差别

- **Android**：截图走 `adb screencap`（远程 adb、无线调试、云手机一样），识别在本机完成；点击是屏幕坐标点按
- **Web**：对页面视口截图识别，点击是真实的鼠标事件
- **Mac 桌面**：识别、断言、捕获只需要截图（和普通截图一样要「屏幕录制」权限），不动你的鼠标。**点击、悬停、填写**屏幕上的文字没有无障碍引用，只能用真实鼠标——需要在 `codebaby.json` 里写：

```json project
{
  "version": 1,
  "desktop": { "headed": true }
}
```

  开启后运行时会把应用窗口带到最前、移动鼠标并点击，期间请不要动鼠标；没开时点击会报错并提示这个开关。填写走剪贴板粘贴（粘贴后恢复原来的剪贴板）

## 识别语言

缺省识别简体中文和英文。要识别别的语言，在 `codebaby.json` 里写：

```json project
{
  "version": 1,
  "ocr": { "languages": ["zh-Hans", "en-US", "ja-JP"] }
}
```

`codebaby doctor` 会检查用到 `ocr` 的用例所需的语言本机是否支持，并列出支持的语言。
